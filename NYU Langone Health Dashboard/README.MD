# NYU Langone Health — FY2025 Financial Dashboard

An interactive financial performance dashboard built from NYU Langone Health's
FY2025-Q4 Annual Report (unaudited), issued November 2025.

## Live Demo
[Open Dashboard]([Open Dashboard](https://rajas9366.github.io/Portfolio/NYU%20Langone%20Health%20Dashboard/NYU%20Langone%20Dashboard.html))

## Features
- 4 tabs: Overview, Facilities, Revenue & Expenses, Payor Mix
- Global slicers for Year (FY2025/FY2024) and Period (Annual/Q4)
- Click-to-filter on all charts, cards, and legend items
- Active filter badges with one-click reset

## Data Source
[NYU Langone Health FY2025-Q4 Annual Report](https://nyulangone.org/files/2025-annual-report.pdf)
· Fiscal year ended August 31, 2025 ·
